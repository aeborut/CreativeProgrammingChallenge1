AdjList OVERVIEW:

AdjList is a class that creates adjacency lists for a node tree structure.
layers -> Integer attribute, reflects the depth of the tree. This is the only
	parameter needed to construct a new object.
nodes -> ArrayList of ArrayList of Integers, list of each node's adjacency list.
	The root node has no parent, so all entries in its list reflect the indices
	of its children.
	Subsequent nodes contain their parent node in index 0, followed by their
	children nodes.

Explanation:
	The nodes attribute is created by first generating a root node, which is populated
	by 2 to 3 children nodes. Their indices are chosen sequentially using the
	indexCount variable to keep track of the current number of nodes added to the
	nodes list.
	Next, a while loop tracks the number of layers generated. Each cycle creates a new
	layer for which each node in the last layer produces 2 to 3 children.
	In the end the adjacency list will contain between 2^(layers) and 3^(layers) nodes.

Branches OVERVIEW:

Branches is a class that takes an adjacency list and converts it to a list of PVectors to be drawn.
branchList -> List of PVectors.
origin -> coordinates for base of tree, taken from input parameter.
adjacencies -> AdjList object described above, used to add vectors head to tail.
rootMag -> magnitude of root vector, subsequent vectors are scaled off of this.

INPUT PARAMETERS:
	PVector object as origin.
	Integer to be passed into AdjList for number of layers.

Explanation:
	The PVector list is generated by iterating through the adjacency list, copying the
	parent vector, scaling down the magnitude, then giving the new vector a random 
	rotation between -90 and 90 degrees.
	Each vector is initially created as if pointing from the (0,0) coordinates of the
	screen, the final step is to use vector addition to assemble the tree from the 
	base vector.

METHODS:
	display() is a method created to draw the tree on the screen. Each line generated
	starts at each node's parent's vector and goes to the node's own vector.

LeafContour2 OVERVIEW:

LeafContour2 is a class that represents a leaf like object.
LeafVertices -> list of PVectors that compose the leaf
rootVector -> PVector extending from the base of the leaf to the tip
N -> Integer representing half the total number of vertices in the leaf
angleStep -> float specifying the angle between each leaf vertex vector
origin -> PVector representing the on screen position of the base of the leaf

INPUT PARAMETERS:
	PVector giving the coordinates of the base of the leaf
	PVector giving the magnitude and orientation of the central line of the leaf
	Integer setting half the total number of vertices on the leaf

Explanation:
	The leaf is generated by creating vectors that are rooted in the base and spiral
	out until reaching the tip of the leaf. Both halves are made at the same time and
	are symmetrical. Initially all vectors are made from (0,0), then added to the
	position vector used as an input parameter.

METHODS
	originTranslate(float x, float y) allows the leaf to be translated in the x and y
	directions on screen.
	leafScale(float R) allows for rescaling the leaf by a factor R.
	pointRotation(float theta, PVector rotPoint) allows the leaf to be rotated around
	a specified point on the screen by an angle theta.
	originRotation(float theta) rotates the leaf object around its own base by an angle
	theta.
